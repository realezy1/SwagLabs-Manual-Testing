# Swag Labs – Manual Testing Portfolio

## 1. Project Overview

This project documents manual testing activities performed on the **Swag Labs (SauceDemo)** web application.

The purpose of this project is to evaluate the application's functionality, identify potential issues, and verify whether each feature works according to its expected behavior.

The testing process includes test case design, test execution, result documentation, and test reporting using Jira and spreadsheet documentation.

**Application Under Test:** https://www.saucedemo.com/

## 2. Project Objectives

- Verify that the main application features work as expected.
- Design and execute functional test cases.
- Perform positive and negative testing.
- Validate application responses against expected results.
- Document test execution results and supporting evidence.
- Practice test case management and defect reporting using Jira.

## 5. Testing Methodology

The testing was performed using a black-box testing approach, focusing on application behavior from the user's perspective without examining the internal source code.

The testing techniques included:

- **Positive Testing:** Verifying functionality with valid input and expected user actions.
- **Negative Testing:** Verifying application behavior with invalid input, missing fields, and unexpected actions.
- **Functional Testing:** Checking whether application features work according to their requirements.
- **Validation Testing:** Comparing actual results with expected results.
- **Regression-oriented Checks:** Rechecking relevant application behavior after performing actions such as adding/removing products and completing checkout.
